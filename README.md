# Зауваження

1. Перейменувати `takeA()`, `takeB()`, `takeC()` на `getA()`, `getB()`, `getC()`.

2. Перейменувати `putA()`, `putB()`, `putC()` на `setA()`, `setB()`, `setC()`.

3. Перевірити необхідність `set`-методів, оскільки через них можна змінити сторони вже створеного трикутника на некоректні значення.

4. Перевіряти коректність сторін трикутника під час створення об'єкта.

5. Перевірити необхідність конструктора без параметрів `Triangle()`, оскільки він дозволяє створити трикутник зі сторонами `0, 0, 0`.

6. Розглянути можливість зробити поля `a`, `b`, `c` незмінними (`final`).

7. Перейменувати `perim()` на `perimeter()`.

8. Перейменувати `equilateral()` на `isEquilateral()`.

9. Спростити `equilateral()` — замість `if/else` безпосередньо повертати результат умови.

10. Не викликати `perim()` декілька разів у `area()` — зберегти напівпериметр в окремій змінній.

11. Покращити читабельність формули в `area()`, розбивши її на кілька логічних частин.

12. Врахувати похибку при порівнянні значень типу `double` у `equilateral()`.

13. Визначити, чи повинні трикутники з однаковими сторонами, але в різному порядку, вважатися рівними в `equals()`.

14. Додати тести для перевірки `perimeter()`, `area()`, `isEquilateral()`, `equals()` та `hashCode()`.
